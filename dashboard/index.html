This dashboard reads from your Supabase tables (messages, escalations, knowledge_base, sentiment_daily) and uses Supabase Auth for login.

The engine on Render receives Facebook/Instagram webhooks via ManyChat, classifies with Claude, and writes results to the same Supabase. The dashboard never talks to Render directly except for the health check.

To add a user, go to Supabase → Authentication → Users → Add user.
